# ValambyaT3ch Portfolio

A one-page portfolio website for ValambyaT3ch Productions, built with plain HTML, CSS, and vanilla JavaScript.

## About
ValambyaT3ch is the brand, and Ntsako Ngobeni is the face behind it. This portfolio is designed to present the founder’s work, skills, and projects in a modern and professional way.

## Features
- Hero section with personal branding
- Services overview
- Work section for PathWise case study
- About section with profile image
- Skills section
- Contact section with WhatsApp and email links
- Mobile responsive layout
- Browser tab favicon
